# โก๋ในซอย HR Hub

ศูนย์สื่อสารฝ่ายบุคคลบน LINE OA สำหรับพนักงานร้านโก๋ในซอย (~60 คน)
พนักงานใช้ผ่านเมนูในไลน์ ไม่ต้องติดตั้งแอปเพิ่ม

---

## ระบบประกอบด้วยอะไรบ้าง

| ส่วน | อยู่ที่ไหน | ทำอะไร |
| --- | --- | --- |
| หน้าเว็บในไลน์ (LIFF) | `*.html`, `app.js`, `app.css`, `config.js` | 8 หน้าที่พนักงานเห็น — ยืนยันตัวตน, ประกาศ, คู่มือ, ตารางงาน, ติดต่อ HR, คู่มือแอป, ผังองค์กร, รายงาน |
| หลังบ้าน | `apps-script/` | Google Apps Script — รับ webhook จากไลน์, ตรวจสิทธิ์, อ่าน/เขียนฐานข้อมูล |
| ฐานข้อมูล | Google Sheet | 15 แท็บ — ดูรายละเอียดในแท็บ "อ่านก่อนใช้งาน" ของชีต |
| ภาพเมนูในไลน์ | `richmenu/` | สร้างจากไฟล์ออกแบบไฟล์เดียวด้วย `richmenu/build.py` |

หน้าเว็บเผยแพร่ที่ **https://manhaqq.github.io/koh-hr-liff/** (GitHub Pages)
หลังบ้านเผยแพร่เป็น Apps Script Web App — URL อยู่ใน `config.js`

## ★ หลักการสำคัญ: ระบบ 0 บาท

แพ็กเกจฟรีของ LINE ส่งข้อความได้แค่ **300 ข้อความ/เดือน** ถ้าส่งแจ้งเตือนหาพนักงาน
60 คนแค่ 5 ครั้งก็หมดโควตาแล้ว ระบบนี้จึงออกแบบให้ **ไม่ใช้การส่งข้อความแจ้งเตือน**

| แทนที่จะ | ระบบทำแบบนี้ | ต้นทุน |
| --- | --- | --- |
| ส่งข้อความว่ามีประกาศใหม่ | **สลับภาพเมนู** ให้มีจุดแดง | ฟรี ไม่จำกัด |
| ส่งข้อความเตือนเข้ากะ | พนักงานกด "เพิ่มลงปฏิทิน" ครั้งเดียว มือถือเตือนเองตลอด | ฟรี |
| ส่งข้อความบอก HR ว่ามีเรื่องใหม่ | ส่งอีเมล | ฟรี |

โควตา 300 ข้อความเก็บไว้ใช้เฉพาะเหตุด่วนจริง ๆ ผ่านเมนู "ส่งด่วนเข้าแชททุกคน"

**ถ้าจะแก้ระบบแจ้งเตือน ให้ระวังหลักการนี้ไว้เสมอ** — การเผลอเปลี่ยนไปใช้ push
message จะทำให้ระบบใช้ไม่ได้ภายในไม่กี่วัน

| Di Serria | `#DBA66B` | ปุ่ม พื้น เส้นขอบ |
| Shadow | `#866B4E` | ตัวอักษรรอง |
| — | `#6B4A2B` | แถบหัวเรื่อง ปุ่มตัวอักษรขาว |
| — | `#9A6B2E` | ตัวอักษรสีแทนบนพื้นสว่าง |

> `#DBA66B` บนพื้นขาวได้ contrast แค่ 2.2:1 ซึ่งอ่านไม่ออก
> ถ้าจะใช้สีแทนเป็น**ตัวอักษร** ต้องใช้ `--accent-ink` (`#9A6B2E`) เท่านั้น

สีถูกประกาศไว้ 4 ที่ **ถ้าจะเปลี่ยนสีต้องแก้ให้ครบทุกที่**

1. `app.css` — ตัวแปร `:root`
2. `config.js` — `THEME`
3. `apps-script/00_Config.js` — `CFG.BRAND` (ใช้กับการ์ด Flex ในแชทและอีเมล)
4. `richmenu/build.py` — ภาพเมนู

## แก้ภาพเมนูในไลน์

```bash
# 1. วางไฟล์ออกแบบใหม่ทับ (ต้องเป็น 2500 x 1686)
cp ~/Downloads/เมนูใหม่.png richmenu/src/base.png

# 2. สร้างภาพทั้ง 5 แบบ (ปกติ + จุดแดง 3 แบบ + เมนูคนที่ยังไม่ยืนยันตัวตน)
python3 richmenu/build.py

# 3. push แล้วรอ GitHub Pages อัปเดตสักครู่
git add richmenu && git commit -m "เมนูใหม่" && git push
```

จากนั้นเปิดชีต → เมนู **🔧 ตั้งค่าระบบ → สร้าง/อัปเดต Rich Menu ทั้งหมด**

> ถ้าย้ายตำแหน่งปุ่มในภาพ ต้องแก้พิกัดใน `apps-script/08_RichMenu.js`
> (`richMenuMainObject_`) ให้ตรงด้วย ไม่งั้นกดแล้วไม่ตรงปุ่ม

## ปล่อยเวอร์ชันใหม่

โค้ดของโปรเจ็คนี้ไปอยู่ **3 ที่ที่เวอร์ชันไม่ผูกกันเอง** สคริปต์นี้ทำให้ตรงกัน

```bash
./scripts/release.sh v0.3.0 "เพิ่มระบบข้อสอบ"
```

## ย้อนกลับเวอร์ชันเก่า

```bash
./scripts/rollback.sh              # ดูว่ามีเวอร์ชันอะไรให้ย้อนบ้าง
./scripts/rollback.sh v0.2.0       # ย้อนกลับ
```

หลังบ้านย้อนได้**ทันทีโดยไม่ต้องแตะโค้ด** เพราะ Apps Script เก็บทุกเวอร์ชันไว้
แค่ชี้ deployment เดิมกลับไปเวอร์ชันเก่า URL ไม่เปลี่ยน พนักงานไม่รู้สึกอะไร

## ตั้งค่าเครื่องสำหรับพัฒนา

```bash
git clone https://github.com/manhaqq/koh-hr-liff.git
cd koh-hr-liff

npm install -g @google/clasp     # เครื่องมือ sync โค้ดหลังบ้าน
clasp login                       # ใช้บัญชี Google ที่เป็นเจ้าของ Apps Script
pip3 install Pillow               # ใช้สร้างภาพ Rich Menu
```

| คำสั่ง | ทำอะไร |
| --- | --- |
| `cd apps-script && clasp pull` | ดึงโค้ดหลังบ้านล่าสุดลงมา (เผื่อมีคนแก้ผ่านหน้าเว็บ) |
| `cd apps-script && clasp push` | อัปโหลดโค้ดขึ้นไป (ยังไม่มีผลกับของจริงจนกว่าจะ deploy) |
| `cd apps-script && clasp open-script` | เปิดหน้า Apps Script editor |

> **Token และรหัสลับทั้งหมดไม่ได้อยู่ในโค้ด** แต่อยู่ใน Script Properties ของ
> Apps Script (⚙️ Project Settings) จึง commit โค้ดขึ้น GitHub ได้อย่างปลอดภัย

## ข้อห้ามของฐานข้อมูล

ชีตเขียนกฎไว้ในแท็บ "อ่านก่อนใช้งาน" **ต้องทำตามเสมอ**

1. ห้ามเปลี่ยนชื่อคอลัมน์ (แถวที่ 1) — โค้ดอ่านชื่อคอลัมน์ตรง ๆ
2. ห้ามลบแถวพนักงานที่ลาออก — กฎหมายให้เก็บทะเบียนลูกจ้างอย่างน้อย 2 ปี
3. ห้ามใส่เลขบัตรประชาชน — เก็บได้แค่เบอร์โทร 4 ตัวท้าย
4. ห้ามใส่เงินเดือนในไฟล์นี้ — ให้แยกไฟล์ที่จำกัดสิทธิ์ต่างหาก
5. ห้ามแชร์แบบ "ทุกคนที่มีลิงก์" — เฉพาะ HR และผู้บริหาร
6. `lineUserId` เป็นข้อมูลส่วนบุคคล ห้ามคัดลอกออกนอกไฟล์นี้
